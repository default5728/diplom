Технічні навички та стек технологій

HTML5 & CSS3

Семантична та адаптивна верстка веб-сторінок. Робота з Flexbox, CSS Grid, медіа-запитами під мобільні пристрої та сучасними анімаціями.

JavaScript (Vanilla JS)

Маніпуляції з DOM-деревом, обробка користувацьких подій, робота з LocalStorage та асинхронні запити через Fetch API.

PHP & MySQL

Базова серверна логіка: обробка POST/GET форм, фільтрація та валідація вхідних даних, взаємодія з реляційною БД (CRUD-операції).

REST API & Інструменти

Інтеграція зовнішніх сервісів через JSON, взаємодія з Telegram Bot API, контроль версій через Git та базове адміністрування веб-хостингів.
